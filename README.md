# סטודיו עיצוב

אפליקציית Next.js ליצירת עיצובים מקטגוריות ותמונות. השלב הנוכחי: ניהול קטגוריות ותמונות ועורך ידני (בלי AI).

## הרצה

```
npm install
npm run dev      # http://localhost:3000
```

הנתונים נשמרים מקומית בתיקייה `data/` (קובץ `db.json` ותיקיית `uploads/`). התיקייה לא נכנסת ל-git.

## משתמשים והרשאות

**כרגע ההתחברות כבויה** (`AUTH_DISABLED` ב-`src/lib/config.ts`, ברירת המחדל פעילה). כל מבקר הוא אורח אנונימי שנזכר לפי עוגייה בדפדפן, עורך כרטיסים בתבניות שפורסמו, ויכול לעבור ל"מצב ניהול" בכפתור בסרגל העליון. להחזרת ההרשמה וההתחברות: להפעיל עם `AUTH_DISABLED=false`.

- נרשמים ב-`/login`. **החשבון הראשון שנרשם הוא המנהל.** כדי לקבוע מנהל מסוים, מגדירים משתנה סביבה `ADMIN_EMAIL` לפני ההרשמה.
- מנהל: בונה תבניות, מסמן אילו טקסטים הלקוח יכול לערוך (ומה שם השדה), מפרסם או מבטל פרסום, מנהל קטגוריות ותמונות.
- לקוח: רואה תבניות שפורסמו, מתחיל מהן כרטיס משלו ועורך בו רק את השדות שסומנו. ההגבלה נאכפת בשרת (`applyCustomerEdits` ב-`src/lib/canvas.ts`), לא רק בממשק.

## מבנה

- `/categories` — יצירת קטגוריות, העלאת תמונות לכל קטגוריה (גרירה או בחירה), שינוי שם ומחיקה.
- `/` — רשימת העיצובים ויצירת עיצוב חדש (A4, A5, ריבוע, סטורי).
- `/editor/[id]` — עורך קאנבס: טקסט (עברית RTL), מלבנים ותמונות מהקטגוריות; גרירה, שינוי גודל, סיבוב, שכבות, שכפול, ביטול/חזרה, שמירה אוטומטית וייצוא PNG ב-300dpi.

## קבצים מרכזיים

- `src/lib/types.ts` — מבנה הנתונים ומסמך הקאנבס (מידות במ״מ).
- `src/lib/canvas.ts` — ולידציה של מסמך הקאנבס, גדלי עמוד ופונטים.
- `src/lib/db.ts` — שכבת האחסון המקומית. כל הגישה לנתונים עוברת דרכה, כדי שאפשר יהיה להחליף ב-MongoDB ו-Cloud Storage לפי האפיון.
- `src/components/Editor.tsx` — העורך.

## השלב הבא

חיבור ה-AI: הוא יחזיר רשימת פעולות עריכה על מסמך הקאנבס הקיים (סעיפים 6 ו-12 באפיון), על אותו מבנה שהעורך הידני משתמש בו.
