# ייבוא מודעות שטוחות (JPG/PNG) לתבניות

כלי שממיר מודעה שהגיעה כתמונה אחת, בלי שכבות, לכרטיס באפליקציה עם טקסטים שאפשר לערוך. לכל מודעה יש תיקייה משלה תחת `ads/`, וכל מודעה נטענת לאפליקציה המקומית ככרטיס נפרד.

| מודעה | מה מיוחד בה |
|---|---|
| `ads/streimel` | טקסט על קופסאות בצבע אחיד ועל גרדיאנט, כותרות אנכיות. המדידות והצבעים הוזנו ידנית |
| `ads/wedding-violin` | הזמנה לחתונה: 25 שורות על לוח לבן. רק מלבנים גסים הוזנו, הכלי מיישר אותם ודוגם את הצבעים |

## שימוש

```
pip install -r examples/ad-import/requirements.txt
python examples/ad-import/adimport.py build  ads/wedding-violin   # יוצר רקע נקי, canvas.json ותצוגה מקדימה
python examples/ad-import/adimport.py import ads/wedding-violin   # טוען את המודעה לאפליקציה ככרטיס
```

`import` יוצר קטגוריית בדיקה עם תמונת הרקע ותבנית מפורסמת. הוא כותב ישירות ל-`data/db.json`, ואפשר להריץ אותו כמה פעמים.
`build` יוצר גם `compare.png`, המקור ליד התוצאה, לבדיקה מהירה (לא נכנס ל-git).

## מודעה חדשה

1. יוצרים תיקייה `ads/<שם>` ומעתיקים אליה את המודעה בשם `source.jpg`.
2. כותבים `spec.json`. כל הקואורדינטות בפיקסלים של המקור (`[x0, y0, x1, y1]`):

```json
{
  "name": "שם התבנית",
  "page": { "width_mm": 210, "height_mm": 297, "background": "#F1E6D3" },
  "tighten": true,
  "rects": [{ "box": [204, 0, 413, 719], "fill": "#F6AA4A" }],
  "texts": [
    { "text": "יעקב", "box": [358, 604, 484, 662], "font": "Frank Ruhl Libre", "weight": 700, "label": "שם החתן" }
  ]
}
```

| שדה | משמעות |
|---|---|
| `texts` | כל שורת טקסט הופכת לשדה שהלקוח יכול לערוך. `font` אחד מהגופנים של האפליקציה, `weight` הוא 400 או 700, `rotation` הוא 0 או 90, `color` לא חובה (נדגם מהתמונה) |
| `tighten` | מכווץ כל `box` לגבולות הדיו האמיתיים. כך מספיק לסמן מלבן גס |
| `rects` | קופסאות בצבע אחיד. הופכות למלבנים בעורך, והטקסט שעליהן לא נמחק מהרקע (המלבן מכסה אותו) |
| `erase` | לא חובה: אזורים למחיקה. ברירת המחדל היא כל טקסט שלא יושב על `rect` |
| `fill_columns` | לא חובה: `[x0, x1, y_top, y_bottom]` למילוי אזור בגרדיאנט חלק, כשהטקסט גדול מדי למחיקה רגילה |

טקסט מעוקל, קליגרפיה ולוגואים לא נכנסים ל-`texts`, ונשארים חלק מתמונת הרקע.

## איך זה עובד

1. **מחיקה:** בכל אזור הכלי מחשב את הרקע המקומי (חציון), מסמן את הפיקסלים שבולטים ממנו וממלא אותם (inpainting של OpenCV).
2. **גודל גופן:** נקבע לפי הגופן האמיתי (מורד מ-Google Fonts), כך שהטקסט ימלא את המקום המקורי בלי לגלוש לשורה נוספת.
3. **המרה:** הכלי ממיר למסמך קאנבס במ״מ. התמונה מקבלת מזהה זמני `BACKGROUND`, ו-`import` מחליף אותו במזהה התמונה שהועלתה.

## מגבלות

- אם הגופן במודעה צר מהגופנים באפליקציה, מילים רחבות יוצאות קטנות יותר.
- אין קו תחתון, צל או קו מתאר.
- טקסט בכמה צבעים מתפצל לכמה שדות.
- טקסט על תמונה עם פרטים (פנים, מוצר, דוגמה) נמרח במחיקה. צריך כלי AI לתמונות או תיקון ידני.
- הנתונים ב-`spec.json` עדיין נכתבים ידנית. השלב הבא הוא לתת ל-Claude לקרוא את התמונה ולכתוב אותם.
