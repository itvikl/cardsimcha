# דוגמה: ייבוא מודעה שטוחה (JPG) לתבנית

מודעה שהגיעה כתמונה אחת, בלי שכבות, שהומרה לתבנית עם טקסטים שאפשר לערוך.

| קובץ | מה זה |
|---|---|
| `source.jpg` | המודעה המקורית |
| `background.jpg` | המודעה אחרי הסרת הטקסטים שישבו על התמונה ועל הגרדיאנט |
| `canvas.json` | מסמך הקאנבס (מ״מ, A4): רקע, 5 מלבנים ו-18 שדות טקסט. מזהה התמונה הוא `BACKGROUND` |
| `preview.png` | תצוגה מקדימה גסה (העברית והמספרים הפוכים בה, רק לבדיקת מיקומים) |

## ייבוא לאפליקציה

```
pip install -r examples/ad-import/requirements.txt
python examples/ad-import/import.py
```

נוצרות קטגוריית בדיקה עם תמונת הרקע ותבנית מפורסמת. הסקריפט כותב ישירות ל-`data/db.json`, ואפשר להריץ אותו כמה פעמים.

## איך זה נבנה (לשחזור במודעה הבאה)

1. **מדידה:** כל בלוק טקסט נמדד בפיקסלים של המקור: מלבן הדיו, סיבוב, צבע וגופן. הנתונים נמצאים ברשימות `rects` ו-`texts` ב-`build.py`.
2. **`clean.py`:** מוחק מהרקע טקסט שיושב על תמונה או גרדיאנט (inpainting של OpenCV). טקסט על קופסה בצבע אחיד לא נמחק, כי מלבן בעורך מכסה אותו.
3. **`build.py`:** ממיר את המדידות למסמך קאנבס. גודל הגופן נקבע לפי הגופן האמיתי (Secular One או Heebo), כך שהטקסט ימלא את המקום המקורי בלי לגלוש לשורה נוספת.

## מגבלות

- הגופן במודעה צר, ובאפליקציה אין גופן דומה. לכן מילים רחבות יוצאות קטנות יותר.
- אין קו תחתון ואין צל לטקסט.
- טקסט בכמה צבעים מתפצל לכמה שדות (יום, תאריך, שעות).
